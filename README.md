# พอร์ตโฟลิโอส่วนตัว — Suppkrit Karawa

พอร์ตโฟลิโอของ **Suppkrit Karawa (บีม)** นักศึกษาแผนกวิชาเทคโนโลยีสารสนเทศ
วิทยาลัยอาชีวศึกษานครศรีธรรมราช สนใจระบบคอมพิวเตอร์ ฮาร์ดแวร์ และการพัฒนาซอฟต์แวร์

เว็บไซต์เขียนด้วย **HTML5, CSS3 และ Vanilla JavaScript ล้วน** ไม่มีเฟรมเวิร์ก
ไม่มี dependency และไม่มีขั้นตอน build ใด ๆ — เปิดไฟล์ `index.html` ก็ใช้งานได้ทันที

## จุดเด่น

- **Dashboard layout** — sidebar คงที่ + top bar ที่เปลี่ยนหัวข้อตามส่วนที่เลื่อนถึง
- **ธีม dark terminal** — พื้นดำ เขียว neon `#00FF9C` และฟ้า `#00D9F5`
- **Terminal animation** — พิมพ์คำสั่งทีละตัวอักษรพร้อมเคอร์เซอร์กระพริบ
- **ภาษาไทยทั้งหน้า** — ใช้ฟอนต์ Noto Sans Thai คู่กับ Inter และ JetBrains Mono
- **Responsive เต็มรูปแบบ** — sidebar กลายเป็น drawer บนจอเล็ก ไม่มี horizontal overflow
- **เข้าถึงได้** — skip link, `aria-*`, โฟกัสมองเห็นชัด และรองรับ `prefers-reduced-motion`
- **ไม่มีตัวเลขความสามารถของสกิล** — แสดงเฉพาะเทคโนโลยีที่ใช้จริง ไม่กุเปอร์เซ็นต์

## เริ่มใช้งาน

ไม่ต้องติดตั้งอะไรเลย เลือกวิธีใดวิธีหนึ่ง

**1. เปิดไฟล์ตรง ๆ**

ดับเบิลคลิก `index.html` ได้ทันที (ทุกอย่างทำงาน ยกเว้นไม่มี HTTP server)

**2. รัน static server (แนะนำ)**

```bash
# ถ้ามี Node.js
npx serve .

# ถ้ามี Python 3
python -m http.server 5500
```

แล้วเปิด <http://localhost:5500>

**3. VS Code**

ติดตั้งส่วนขยาย **Live Server** → คลิกขวาที่ `index.html` → *Open with Live Server*

> หมายเหตุ: ไฟล์ SVG ใน `assets/icons/` ถูกเรียกผ่าน CSS `mask-image`
> จึงควรเปิดผ่าน HTTP server เพื่อไม่ให้เบราว์เซอร์บางตัวบล็อกไฟล์จาก `file://`

## เนื้อหาภายในเว็บ

หน้าเดียว เลื่อนต่อเนื่อง แบ่งเป็น 6 ส่วน — เมนู sidebar แต่ละอันชี้ไปยัง section ด้านล่าง

| # | Section | id | เนื้อหา |
|---|---------|----|---------|
| 1 | หน้าหลัก | `#home` | การ์ดโปรไฟล์, เทอร์มินัล, ทักษะเด่น |
| 2 | เกี่ยวกับฉัน | `#about` | แนะนำตัว + ข้อมูลพื้นฐาน |
| 3 | การศึกษา | `#education` | วิทยาลัยอาชีวศึกษานครศรีธรรมราช |
| 4 | ทักษะ | `#skills` | 4 หมวด: หน้าเว็บ, การเขียนโปรแกรม, เครื่องมือ, ระบบปฏิบัติการ |

## การทำงานของ JavaScript

`js/script.js` เป็น IIFE เดียว ทำงาน 6 อย่าง — ไฟล์นี้เป็น vanilla JS ล้วน
ไม่มีการ import ใด ๆ

1. **Sidebar drawer** — เปิด/ปิดด้วย `#menuBtn`, ปิดด้วย backdrop, ปุ่ม Escape
   หรือเมื่อคลิกเมนู พร้อมอัปเดต `aria-expanded` และล็อกการเลื่อนพื้นหลัง
2. **สถานะ top bar** — เติมคลาส `is-scrolled` เมื่อเลื่อนหน้าเกิน 8px
3. **Active section** — ไฮไลต์เมนูตามการเลื่อน และสลับหัวข้อ/คำอธิบายบน top bar
   จาก `data-title` / `data-sub`
4. **Scroll reveal** — ใช้ `IntersectionObserver` เติมคลาส `is-visible`
   ให้ element ที่มีคลาส `.reveal`
5. **Terminal typing** — พิมพ์คำสั่งทีละตัวอักษรจาก `TERMINAL_SCRIPT`
   แล้วปิดท้ายด้วยบรรทัดพร้อมเคอร์เซอร์กระพริบ
6. **ปีใน footer** — เขียนปี พ.ศ. ปัจจุบันอัตโนมัติ (`ค.ศ. + 543`)

ถ้าผู้ใช้ตั้งค่า *ลดการเคลื่อนไหว* ในระบบ (`prefers-reduced-motion`):
animation ทั้งหมดจะถูกปิด reveal แสดงทันที และเทอร์มินัลใช้ข้อความ static ที่มีใน HTML

## การปรับแต่ง

### ใส่รูปโปรไฟล์

บันทึกรูปชื่อ `profile.jpg` ไว้ที่ `assets/images/profile.jpg` แล้วรีเฟรช
รูปจะแทนที่ placeholder อัตโนมัติ (ถ้าไม่มีไฟล์ จะเห็นวงกลมตัวอักษร `B` แทน
โดยไม่ทำให้เลย์เอาต์พัง)

### เปลี่ยนช่องทางติดต่อ

แก้ที่ section `#contact` ใน `index.html` — มี 3 รายการ คือ GitHub, อีเมล
และ LinkedIn ที่ยังเป็น placeholder (คลาส `is-placeholder`, `aria-disabled="true"`)
เมื่อมีโปรไฟล์จริงแล้ว ให้เปลี่ยน `href` เป็นลิงก์จริงและลบคลาส/แอตทริบิวต์เหล่านั้นออก

### แก้ข้อความในเทอร์มินัล

แก้ที่ตัวแปร `TERMINAL_SCRIPT` ใน `js/script.js` — แต่ละบรรทัดมี `type`
เป็น `"cmd"` (พิมพ์ทีละตัวพร้อมพรอมป์ `$`) หรือ `"out"` (แสดงผลลัพธ์ทันที)
และอย่าลืมแก้ข้อความตั้งต้นใน `<div id="terminalBody">` ใน HTML ให้ตรงกัน
เพราะข้อความชุดนั้นคือสิ่งที่ผู้ใช้เห็นเมื่อปิด animation

### เพิ่มเมนู/section ใหม่

1. เพิ่ม `<section class="block" id="ชื่อ-ใหม่" data-title="…" data-sub="…">` ใน `<main>`
2. เพิ่ม `<a class="side-link" href="#ชื่อ-ใหม่">` ใน `<nav class="side-nav">`

สคริปต์จะจับคู่เมนูกับ section ให้เองโดยอัตโนมัติ ไม่ต้องแก้ JS

### เปลี่ยนสีทั้งเว็บ

แก้ตัวแปรใน `:root` ที่ต้นไฟล์ `css/style.css` เท่านั้น สีที่เกี่ยวข้อง
(`--primary-soft`, `--primary-line` ฯลฯ) ควรปรับตามเพื่อความกลมกลืน

## Responsive

| ความกว้าง | การเปลี่ยนแปลง |
|-----------|----------------|
| มากกว่า 1200px | sidebar 248px, การ์ดทักษะ 4 คอลัมน์, หน้าหลัก 2 คอลัมน์ |
| ≤ 1200px | คอลัมน์การ์ดโปรไฟล์แคบลง, การ์ดทักษะเหลือ 2 คอลัมน์ |
| ≤ 1024px | sidebar เป็น off-canvas drawer + ปุ่ม hamburger, หน้าหลักเหลือ 1 คอลัมน์ |
| ≤ 860px | กริด 2 คอลัมน์ (ความสนใจ) เหลือ 1 คอลัมน์ |
| ≤ 640px | ระยะห่างแคบลง, การ์ดทักษะ 1 คอลัมน์, รูปโปรไฟล์เป็นจัตุรัส, ซ่อนชื่อผู้ใช้บน top bar |

ทดสอบที่ 390 / 768 / 1024 / 1280 / 1440 px — ไม่มี horizontal overflow

3. เลือก **Source: Deploy from a branch** → Branch: `main` → Folder: `/ (root)`
4. รอสักครู่ เว็บจะอยู่ที่ `https://suppakrit14.github.io/suppkrit_profile/`

ทั้งหมดเป็นไฟล์ static จึงไม่ต้องตั้งค่า build ใด ๆ

## หมายเหตุ

- ไม่มี dependency, ไม่มี `package.json` และไม่มีขั้นตอน build — แก้ไฟล์แล้วรีเฟรชได้เลย
- ไม่แสดงเปอร์เซ็นต์ความสามารถของสกิล เพราะเป็นตัวเลขที่วัดไม่ได้จริง
  ใช้ placeholder หรือ "ยังไม่มีข้อมูล" แทนเมื่อข้อมูลยังไม่มี
- ชื่อ-นามสกุลคงเป็นอักษรโรมัน `Suppkrit Karawa` เพื่อไม่ให้สะกดผิด
  ส่วน "บีม / Beam" ใช้เป็นชื่อเล่น
- ไอคอนทั้งหมดดึงจาก Simple Icons และเก็บไว้ในโปรเจกต์เอง
  จึงไม่ต้องพึ่ง CDN ภายนอกตอนรัน (ยกเว้นฟอนต์จาก Google Fonts)
